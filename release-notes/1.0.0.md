# 🎉 OPI iOS SDK is out!

OPI iOS SDK 1.0.0 brings OPI payment integration to iPhone, iPad, and macOS POS and ECR applications. Connect to a separate network terminal while the SDK handles TCP communication, XML messages, terminal callbacks, and transaction results.

## Highlights in 1.0.0

- Native Swift API with async/await commands and an asynchronous event stream.
- Two-channel OPI TCP communication using Apple networking APIs and an explicit terminal address.
- Payments, refunds, reversals, and terminal operations.
- Structured transaction results, receipts, and DCC information.
- Separate-channel abort and explicit reprint/repeat-last-message commands.
- Prompt handling of reported connection loss, preserving unknown financial outcomes when the final response is unavailable.
- A separate configurable deadline for abort acknowledgements, without holding up a completed financial result.
- Optional Normal and Extended diagnostics with sanitized protocol logging.
- Finite iOS background execution for active financial exchanges, with unknown results on expiration.
- Manual receipt reprint and repeat-last-message operations.
- Receipts are delivered to the application by default, with terminal printing available when configured.
- Your application owns the payment screen and transaction experience. The SDK contains no overlay or branding components.
